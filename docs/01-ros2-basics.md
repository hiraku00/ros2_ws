# 01. ROS 2 の基本（ノードとトピック）

ROS 2 を初めて触る人向けの入門です。中学生でも読めるように、たとえ話から入ります。

## 1. ROS 2 とは

ロボットを動かすプログラムを、1 つの巨大なプログラムで作ると、作るのも直すのも大変です。
そこで、**小さなプログラムに分けて、お互いにメッセージを送り合う**作り方をします。
その「連絡の仕組み」を提供するのが ROS 2 です。

| たとえ | ROS 2 での名前 | 説明 |
|---|---|---|
| 社員 | **ノード** | 1 つの仕事だけをする小さなプログラム |
| 社内の掲示板 | **トピック** | メッセージを貼る場所。名前がついている |
| 掲示板に貼る人 | **パブリッシャ**（publisher） | トピックにメッセージを送る側 |
| 掲示板を読む人 | **サブスクライバ**（subscriber） | トピックのメッセージを受け取る側 |
| 貼る紙の中身 | **メッセージ** | 数値や文字など。型が決まっている |

社員（ノード）は、相手が誰かを知らなくても、**掲示板の名前さえ合っていれば連絡できます**。
だから、片方だけ作り直したり、あとから 1 人増やしたりできます。

## 2. 最小の例：talker と listener

```
talker ──── my_topic ────→ listener
 (書く)      (掲示板)        (読む)
```

| ノード | 役割 | コード |
|---|---|---|
| talker | `my_topic` に、1 秒ごとに文字を送る | [talker.py](../src/my_first_pkg/my_first_pkg/talker.py) |
| listener | `my_topic` に文字が届いたら表示する | [listener.py](../src/my_first_pkg/my_first_pkg/listener.py) |

これだけでは地味ですが、**中身を入れ替えるとロボットになります**。

| この例 | 本物のロボット |
|---|---|
| talker（文字を送る） | LiDAR（距離センサー）が周囲との距離を送る |
| listener（受け取って表示） | 「障害物が近いから止まろう」と判断するプログラム |

## 3. なぜ Docker を使うのか

ROS 2 は Ubuntu（Linux）で動かす前提で作られています。Mac（macOS）にはそのまま入りません。
そこで Docker で、Mac の中に **Ubuntu の小部屋（コンテナ）** を作り、その中で ROS 2 を動かします。

```
Mac (macOS)
 └─ Docker
     └─ コンテナ = Ubuntu の小部屋  ← ROS 2 はここにある
```

いちばん大事なのは、**「Mac 側」と「部屋（コンテナ）の中」を区別すること**です。

| プロンプトの見た目 | いる場所 | 使えるコマンド |
|---|---|---|
| `~/Practice/ros2_ws ❯` | Mac 側 | `docker`、`git` |
| `root@xxxx:/#` | コンテナの中 | `ros2`、`colcon` |

間違った側でコマンドを打つと、`ros2: command not found` や `docker: command not found` が出ます。

## 4. パラメータとは

ノードの**設定値**です。動いている最中に、外から読んだり変えたりできます。

```python
self.declare_parameter('turn_distance', 3.0)      # 名前と初期値を宣言する
value = self.get_parameter('turn_distance').value  # 使うたびに読み直す
```

```bash
ros2 param set /brain turn_distance 10.0   # 実行中に変更する
```

| 変え方 | いつ反映されるか | 再起動後 |
|---|---|---|
| コードの `declare_parameter` の初期値を書き換える | 保存して再起動したとき | その値 |
| `ros2 run ... --ros-args -p 名前:=値` | 起動する瞬間 | 指定した値 |
| `ros2 param set` | **実行中、すぐ** | 初期値に戻る |

**実行中の変更が効くのは、値を読むコードが「メッセージが届くたびに」実行される場所にあるからです。**
`__init__` で 1 回だけ読むと、あとから変えても反映されません。

## 用語集

| 用語 | 意味 |
|---|---|
| ノード | ROS 2 で動く 1 つのプログラム |
| トピック | ノード間の掲示板。名前で区別する |
| パブリッシャ | トピックに書く側 |
| サブスクライバ | トピックを読む側 |
| メッセージ | トピックに流れるデータ。`Float32`（数値）や `String`（文字）など |
| パラメータ | ノードの設定値。実行中に変えられる |
| パッケージ | ノードのコードをまとめた「箱」 |
| colcon | コードを実行できる形に変換する（ビルドする）道具 |
| コンテナ | Docker で作る小さな Ubuntu の部屋 |
