# 04. つまずきやすい点と対処（ステップ 2）

## 1. ロボットが思ったとおりに動かない

| こうなったら | 原因 | こうする |
|---|---|---|
| 少し動いて、すぐ止まる | 指示を 1 回しか送っていない | `ros2 topic pub` に `-r 10` を付けて、送り続ける（[02 の 4 章](02-room-sim.md#4-指示が止まったら止まる暴走防止)） |
| 壁の前で、前に進まない | 進むと、壁にめり込むので、取り消されている | その場で回る（`angular.z` を送る）。向きが変われば、進める |
| 位置が (10, 10) に戻った | `room_sim` を起動し直した | 正常。位置は、起動し直すとスタートに戻る |
| 2 つのロボットに命令しているような、変な動き | 古い `avoider` が、裏で動いたまま | 古いほうを Ctrl+C で止める（5 章） |

## 2. 図（ブラウザ）が思ったとおりに見えない

| こうなったら | 原因 | こうする |
|---|---|---|
| 真っ白、またはファイルがない | `room_sim` が動いていない | タブ 1 で `ros2 run room_robot_pkg room_sim` |
| 図が変わらない | `room_sim` が止まった。または、ロボットが止まっているだけ | 左上の `x`・`y`・`θ` が変わるか見る。変わらなければ、ブラウザを再読み込み |
| 灰色の線ばかり | まわり 12 m 以内に、何もない（`inf`） | 正常。壁に近づくと、赤くなる |
| 回り始めた位置を、見のがす | 図は 1 秒に 1 回しか変わらない | タブ 1（`room_sim`）の「回り始めた」のログを見る |

## 3. 数字の意味が分からない

| 疑問 | 答え | くわしく |
|---|---|---|
| `linear.x: 0.5` は、0.5 m ずつ進むこと？ | いいえ。**速さ**（1 秒で 0.5 m）。1 歩（0.1 秒）では 0.05 m | [01 の 4.2](01-lidar-and-twist.md#42-05-は1-回に進む距離ではなく速さ) |
| 壁まで行ったのに、x = 20 にならない | ロボットは半径 0.3 m の円。中心は 19.7 より先へ行けない | [03 の実験 2](03-experiments.md) |
| 19.7 ではなく 19.65 で止まる | コンピュータの小数のずれで、95 歩目が「めり込み」判定になる | [03 の実験 2](03-experiments.md) |
| 0.3 m は直径？ 半径？ | **半径**。直径は 0.6 m | |
| なぜ回る必要があるの？ | 前に進むだけでは、壁の前で止まるだけ。よけるには、向きを変える | [01 の 4.1](01-lidar-and-twist.md#41-指示は2-つの数字) |
| 360 本なのは、なぜ？ 365 では？ | 円 1 周が 360°。365 は 1 年の日数 | [01 の 3.1](01-lidar-and-twist.md#31-lidar-とは) |
| 6.28 秒回したのに、180° ではなく 172° | `pub` の準備に約 0.7 秒。指示は 56 回だけ | [03 の実験 3](03-experiments.md) |
| `publishing #143` で時間を計算したら、合わない | 止まったあとも、Ctrl+C まで送り続けている | 時間は「距離 ÷ 速さ」で出す |

## 4. コマンドやファイルのエラー

| こうなったら | 原因 | こうする |
|---|---|---|
| `grep: /tmp/sim.log: No such file or directory` | ログは**コンテナの中**にできる。Mac 側のタブ（`❯`）で実行した | コンテナの中のタブ（`root@...:/#`）で実行する |
| `ros2 pkg create` で `required: package_name` | `--dependencies` の後ろに、パッケージ名を書いた | パッケージ名を、先に書く（下の例） |
| `No executable found` | `setup.py` に登録していない、またはビルドし直していない | `setup.py` に 1 行足して、`colcon build` → `source install/setup.bash` |
| `avoider` を起動しても、何も表示されない | 正常。`avoider` は、画面に何も出さない | 動きは、ブラウザの図と、`room_sim` のログで見る |

```bash
# パッケージ名を先に書く
ros2 pkg create room_robot_pkg --build-type ament_python --dependencies rclpy sensor_msgs geometry_msgs
```

## 5. 後片づけ（特に、テストのあと）

動かしたノードは、止めるまで、裏で動き続けます。**残ったノードは、次の実験にまざります。**

| 気をつけること | やりかた |
|---|---|
| 動いているノードを調べる | `ps -eo pid,lstart,args \| grep "[r]oom_sim\|[a]voider"`（起動した時刻も出る） |
| **`pkill -f` は使わない** | コンテナのシェルまで止めてしまったことがある。**番号（PID）を指定して `kill`** する |
| テスト用は、ドメインを分ける | `export ROS_DOMAIN_ID=42` のように、ちがう番号にすると、メッセージがまざらない |

## 用語集

| 用語 | 意味 |
|---|---|
| PID | 動いているプログラム 1 つ 1 つに付く番号 |
| ドメイン ID（`ROS_DOMAIN_ID`） | 同じ番号のノードどうしだけが、話せる。実験を分けるのに使う |
| ログ | プログラムが、画面やファイルに書き出す記録 |
