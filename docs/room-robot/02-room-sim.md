# 02. room_sim の仕組み ― 部屋・ロボット・レーザー

> **この章でわかること**
>
> - `room_sim` が、0.1 秒ごとに何をしているか
> - ロボットが、壁にめり込まない仕組みと、指示が止まったら止まる仕組み
> - ブラウザの図の見かたと、設定（パラメータ）の変えかた

`room_sim` は、**部屋の世界と、ロボットの体（目と足）**を受け持つノードです。コードは [room_sim.py](../../src/room_robot_pkg/room_robot_pkg/room_sim.py) です。
学習の中心は「頭」（`avoider`）なので、`room_sim` は先に用意しました。中身を知っておくと、頭を作るときに役立ちます。

## 1. `room_sim` の 3 つの仕事

| 仕事 | 相手 | 回数 |
|---|---|---|
| ① 指示（`/cmd_vel`）を受け取って、ロボットを動かす | `avoider`、または手で送った指示 | 指示が来るたび |
| ② 360 本のレーザーの距離を、`/scan` で送る | `avoider` | 1 秒に 10 回 |
| ③ 部屋の図を、ファイルに書き出す | ブラウザ | 1 秒に 1 回 |

部屋の大きさや障害物の場所は、[01 の地図](01-lidar-and-twist.md#2-部屋の地図)のとおりです。

## 2. 0.1 秒ごとの「1 歩」

`room_sim` は、**0.1 秒ごとに、次の 5 つを順番に**くり返します。

| 順 | すること |
|---|---|
| 1 | 最後の指示から 0.5 秒以上たっていたら、速さを 0 にする（→ 4 章） |
| 2 | 向きを変える：回った角度 ＝ 回る速さ × 0.1 秒 |
| 3 | 位置を動かす：進んだ距離 ＝ 進む速さ × 0.1 秒 |
| 4 | 壁や障害物にめり込むなら、3 の移動を取り消す（→ 3 章） |
| 5 | 360 本のレーザーの距離を計算して、`/scan` で送る（→ 6 章） |

### 2.1 向きによって、x と y の増えかたが変わる

1 歩で進む距離が同じでも、**向いている方向**で、x と y の増えかたが変わります。
`linear.x = 0.5`（1 歩 0.05 m）のときの例です。

| 向き | x の増えかた | y の増えかた |
|---|---|---|
| 右（0°） | ＋0.05 | 0 |
| 上（90°） | 0 | ＋0.05 |
| 左（180°） | −0.05 | 0 |
| 右ななめ上（45°） | ＋0.035 | ＋0.035 |

ななめのときは、0.05 m を、x 方向と y 方向に**分けて**進みます。だから、それぞれは 0.05 より小さくなります。

> **もっと知りたい人へ**：この「分けかた」は、高校で習う cos（コサイン）と sin（サイン）で計算します。45° のときは、どちらも約 0.71 倍なので、0.05 × 0.71 ≒ 0.035 です。

## 3. 壁にめり込まない仕組み

ロボットは点ではなく、**半径 0.3 m の円**です（直径 0.6 m）。
1 歩動いた先で、円が壁や障害物に重なるなら、**その 1 歩の移動を取り消します**。

| 相手 | めり込みの判定 |
|---|---|
| 壁 | 中心が、壁から 0.3 m 以内に入ったら |
| 円の障害物 | 中心どうしの距離が、1.5 ＋ 0.3 ＝ 1.8 m より近くなったら |
| 四角の障害物 | 四角のいちばん近い点まで、0.3 m より近くなったら |

**取り消すのは、位置だけ**です。向きは変わります。だから、壁の前で止まっても、その場で回れば、向きを変えて出られます。

例：右の壁（x = 20）の前では、中心は **x = 19.7 より右へは行けません**（20 − 0.3）。実際に止まった位置は、[03 の実験 2](03-experiments.md#実験-2-壁までまっすぐ進む) で確かめています。

## 4. 指示が止まったら、止まる（暴走防止）

`/cmd_vel` は、**1 回送れば終わりではありません**。「いま、この速さで」と、**送り続ける**ものです。

`room_sim` は、**最後の指示から 0.5 秒たつと、速さを 0 にして止まります**（パラメータ `cmd_timeout`）。

| 時間 | 起きること |
|---|---|
| 0.0 秒 | 「0.5 m/秒で進め」が届く → 進む |
| 0.1〜0.4 秒 | 指示が来ない。でも、最後の指示のまま進む |
| 0.5 秒 | 指示が来ないまま 0.5 秒 → **止まる** |

頭のプログラムが止まったり、通信が切れたりしたとき、ロボットが走り続けないための**安全装置**です。本物のロボットの多くも、同じ仕組みを持っています。

## 5. 「回り始めた」「回るのをやめた」のログ

回る速さが 0 から 0 以外に変わった**瞬間だけ**（またはその逆）、位置をログに出します。

```
[room_sim]: 回り始めた: x=18.52 y=10.00 θ=3°
[room_sim]: 回るのをやめた: x=18.54 y=10.02 θ=40°
```

ブラウザの図は 1 秒に 1 回しか変わらないので、「どこで回り始めたか」を見のがします。ログなら、その瞬間の位置が分かります。

## 6. レーザーの距離の計算

1 本のレーザーを、**ロボットの中心から、ある向きにまっすぐのびる線**と考えます。
その線を、壁 4 枚・四角の 4 辺・円 1 つに**ぶつかる所まで**のばします。**いちばん近くでぶつかった所**までの長さが、そのレーザーの距離です。これを 360 本ぶん、くり返します。

```
          壁
   🤖 ────────→ │      この長さが、そのレーザーの距離
                │
```

この方法を、**レイキャスト**（光線を投げる、という意味）と呼びます。

> **もっと知りたい人へ**：「線と線がぶつかる所」は連立方程式（中学 2 年）、「線と円がぶつかる所」は二次方程式（中学 3 年）で求めています。

### 6.1 `inf` になるとき

| 条件 | 値 |
|---|---|
| いちばん近い所が、12 m（`range_max`）より遠い | `inf` |
| いちばん近い所が、0.1 m（`range_min`）より近い | `inf` |

スタート位置では、360 本のうち **70 本が `inf`** です（[01 の図](01-lidar-and-twist.md#33-例スタート位置で測ると)の灰色の線）。

### 6.2 ノイズ

本物のセンサーは、測るたびに、距離が少しずつぶれます。これを**ノイズ**と呼びます。
パラメータ `noise` を 0 より大きくすると、**測れた距離 1 本ずつに、ばらばらの「ぶれ」**を足します。

| `noise` | 正しい距離 10.0 m のレーザーが、測るたびに… |
|---|---|
| 0.0（初期値） | 10.0、10.0、10.0、… |
| 0.5 | 9.553、9.553、9.895、…（実測。9.5〜10.5 の間でばらつく） |

`inf` には、ぶれを足しません。ノイズの影響は、[06](06-noise-and-filter.md) でくわしく調べます。

## 7. ブラウザの図の見かた

`room_sim` は、1 秒ごとに `output/index.html` を書き出します。ブラウザで次を開くと、1 秒ごとに図が新しくなります。

```
file:///Users/hiraku/Practice/ros2_ws/output/index.html
```

| 見えるもの | 意味 |
|---|---|
| 青い丸 | ロボット。濃い青の線が、向いている方向 |
| 茶色の丸・四角 | 障害物 |
| **赤い線** | 壁や障害物まで、距離が測れたレーザー |
| **灰色の線** | 12 m 以内に何もなかったレーザー（`inf`） |
| 左上の文字 | ロボットの位置と向き（`x`、`y`、`θ`） |

線は、見やすくするため、5 本に 1 本（72 本）だけ描いています。

## 8. 設定（パラメータ）を変える

動かしている間に、`ros2 param set /room_sim <名前> <値>` で変えられます。

| 名前 | 初期値 | 意味 |
|---|---|---|
| `noise` | 0.0 | ノイズの大きさ（± 何 m ぶれるか） |
| `range_max` | 12.0 | 測れる、いちばん遠い距離（m） |
| `cmd_timeout` | 0.5 | 指示が何秒来なければ止まるか |
| `output_dir` | `/root/ros2_ws/output` | 図を書き出す場所 |

**ためしてみよう**

```bash
ros2 param set /room_sim range_max 20.0
```

| 設定 | `inf` の本数（スタート位置） | 理由 |
|---|---|---|
| `range_max` 12.0 | 70 本 | 四すみの方向は、12 m より遠い |
| `range_max` 20.0 | **0 本** | いちばん遠い角でも 14.14 m なので、全部とどく |

## 9. 動かしかた

Ghostty のタブごとに `docker exec -it ros2 bash` で、コンテナに入ってから実行します。

```bash
# タブ 1：シミュレータ
ros2 run room_robot_pkg room_sim

# タブ 2：手で動かす（Ctrl+C で止める）
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5}, angular: {z: 0.0}}"
```

`-r 10` は、「1 秒に 10 回、送り続ける」という意味です。付けないと、1 回だけ送って、0.5 秒後に止まります（4 章）。

ビルドが必要なのは、初回と、`setup.py` を変えたときだけです。

```bash
cd /root/ros2_ws
colcon build --symlink-install --packages-select room_robot_pkg
source install/setup.bash
```

> **`room_sim` を起動し直すと、ロボットはスタート位置 (10, 10)・右向きに戻ります。** 位置は、プログラムの変数にしか覚えていないからです。

## まとめ

| 覚えること | 内容 |
|---|---|
| 1 歩 | 0.1 秒ごとに、向きを変える → 進む → めり込みを確かめる → レーザーを測る |
| めり込み | ロボットは半径 0.3 m の円。めり込むなら、その 1 歩は取り消し |
| 暴走防止 | 指示が 0.5 秒来なければ、止まる |
| `inf` | 12 m より遠い、または 0.1 m より近いと、`inf` |
| ノイズ | `noise` を上げると、距離が 1 本ずつばらばらにぶれる |

## 用語集

| 用語 | 意味 |
|---|---|
| シミュレータ | 本物の代わりに、コンピュータの中で世界を動かすプログラム |
| レイキャスト | 線をのばして、最初にぶつかる所までの距離を求める方法 |
| ノイズ | 測るたびに、値がばらばらにぶれること |
| パラメータ | ノードを動かしたまま変えられる設定 |
